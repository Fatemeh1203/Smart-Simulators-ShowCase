# Python Basics — Interactive Course
### پایتون مقدماتی — دوره‌ی تعاملی
**Instructor / مدرس: Fatemeh Shams — فاطمه شمس**

A self-contained interactive Python course for absolute beginners (grades 10–12).
Everything lives in a single file: `index.html`. No build step, no dependencies to install.

یک دوره‌ی کامل و مستقلِ پایتون برای مبتدیان مطلق (پایه‌ی دهم تا دوازدهم).
همه‌چیز در یک فایل است: `index.html`. بدون نیاز به نصب یا مراحل ساخت.

---

## What's inside / محتوای دوره
- **14 lessons** — print, variables, str/int/float, conversion, input, math + the `math` library, conditions (if/elif/else), for + range + len, while, break/continue, nested loops, combining if with loops, lists with all their methods, and a lists-with-loops capstone.
- **42 worked examples** with expected output.
- **A live code playground** — real Python runs in the browser (Pyodide). `input()`, `math`, and `random` all work.
- **140 quiz questions** (10 per lesson) + a **40-question random final exam**.
- **Answer key** — correct answer and an explanation under every question.
- **Report card** — per-topic scores, overall average, print / save-as-PDF.
- Light & dark themes, Python logo, saved progress.
- **Default language English**, switchable to Persian (full RTL) from the top bar.

## چهارده درس، ۴۲ مثال حل‌شده، کارگاه کد زنده، ۱۴۰ سؤال آزمون + آزمون جامع ۴۰ سؤالی، پاسخ‌نامه، و کارنامه‌ی قابل چاپ. زبان پیش‌فرض انگلیسی و قابل تغییر به فارسی.

## How to use / نحوه‌ی استفاده

### 1. Open locally / اجرای محلی
Double-click `index.html`. It opens in any modern browser (Chrome, Edge, Firefox, Safari).
فقط روی `index.html` دوبار کلیک کنید؛ در هر مرورگر مدرنی باز می‌شود.

### 2. Publish online / انتشار آنلاین
Upload the whole `python-basics` folder to any static host. Nothing else is required.
کل پوشه‌ی `python-basics` را روی هر میزبان استاتیکی بارگذاری کنید. راه‌های رایگان و ساده:

- **GitHub Pages** — create a repo, upload the folder, enable Pages (see `DEPLOY.md`).
- **Netlify / Vercel / Cloudflare Pages** — drag-and-drop the folder onto the dashboard.
- **Your own server** — copy the folder into the web root.

---

## Requirements / پیش‌نیازها
- The lessons, examples (with output), quizzes, exam, and report card work **offline**.
- Only the **Run** button (live code) needs internet the first time, to load the Python engine (~10 s) from a CDN.
- درس‌ها، مثال‌ها، آزمون‌ها و کارنامه **بدون اینترنت** کار می‌کنند. فقط دکمه‌ی «اجرا» بار اول برای بارگذاری موتور پایتون به اینترنت نیاز دارد.

> ⚠️ An infinite loop (a `while` with no end) will freeze the tab — reload the page if that happens.
> ⚠️ حلقه‌ی بی‌پایان صفحه را قفل می‌کند؛ در این صورت صفحه را دوباره بارگذاری کنید.
